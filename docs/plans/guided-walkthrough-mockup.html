02

What the agent writes

The chapter on screen, as authored. The outlined step is the one showing; click any step or folded chapter to go there.
walkthrough.json· validated by a Zod schema · prose fields are narrative HTML

  
Rendered step




Only three things carry meaning: lead (static per chapter, may hold an <rr-flow>), step text, and an optional step ref. A step without ref keeps the last target, or shows the chapter's diagram. Shared as a fenced ```reviewroom-walkthrough block in a PR comment, reviewroom pulls it from the PR.

Player states
One XState machine; the current state follows the player above.



  

    
    
now: 

  

  

    
open
From the header's Walkthrough button. Starts at chapter 1, step 1.

    
next · prev · goto
Buttons, ← → keys, the chapter menu and the progress ticks. Crosses chapter edges.

    
comment
Opens the usual composer with anchor { kind: "tour", chapter, step }. Stays in playing; the thread lives in the Threads panel.

    
pause · resume
Pause shrinks to the pill; the workbench is fully usable. Resume returns to the same step.
