Attach recent HABIT events to the ranker request

The request builder now reads the user's last 7 days of HABIT events through TFS v2 and passes them to the ranker as a new proto field. If the fetch fails the feed still serves, just without the signal.

Summary

Three pieces, landed in two commits: a new habit.Fetcher over TFS v2, a HabitEvent message plus field 12 on RankerRequest, and one new call inside Builder.Build. A storage table backs the online store.

FeedRequest Builder.Build Tardis.Fetch habit.RecentEvents tfsv2.BatchGet RankerRequest

Today the builder fetches four base feature keys from Tardis and forwards them; no per-user event history reaches the ranker. HABIT embeddings are computed offline and are unaffected by this PR.

Request path & latency

The habit call runs after the Tardis fetch, sequentially, so its latency adds straight onto the feed request. The fetcher caps itself with a 30 ms deadline. Staging p99s below; toggle to see what running both calls concurrently would buy.

Failure mode

On any fetch error the builder logs at warn level and sends an empty list. Because habit_events is repeated, nil serialises as empty and the ranker reads it as "no signal" rather than an error.

Nothing counts the degraded requests. If TFS v2 started failing for every user, dashboards would stay green while ranking quality dropped. b.metrics is already injected (), so a counter is one line.

Proto & storage

Field 12 is appended, never reused, so older ranker builds simply ignore it. The table is additive and its (user_id, ts DESC) index matches the window read.

Two new tests: the deadline fires () and decoding caps at 50 rows (). Nothing exercises the degrade branch in Build.

Parallel fetch sketch

Added after round 1 (your question on sequencing). Both calls only need the user id, so they can share an errgroup; habit stays best-effort by swallowing its own error.

g, gctx := errgroup.WithContext(ctx) g.Go(func() error { var err error; feats, err = b.tardis.Fetch(gctx, uid, baseKeys); return err }) g.Go(func() error { ev, err := b.habit.RecentEvents(gctx, uid, habitWindow) if err != nil { b.metrics.Inc("habit_degraded_total") return nil // best effort } habitEvents = ev return nil }) if err := g.Wait(); err != nil { return nil, err }
